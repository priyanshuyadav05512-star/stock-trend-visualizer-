# stock-trend-visualizer-
StockTrend Visualizer A beginner-friendly Python project that downloads one year of historical stock data from Yahoo Finance and turns it into a clear, two-panel chart. The top panel shows the daily closing price along with 20-day and 50-day moving averages, while the bottom panel shows trading volume.
Purpose
Daily stock prices move up and down constantly, which makes it hard to see the bigger picture. This project smooths out that noise using moving averages, so the underlying trend becomes easy to spot. Showing volume below the price chart also reveals how much trading activity supported each price move.
What it's useful for
Spotting whether a stock is in an uptrend or downtrend
Identifying possible crossover signals, where the 20-day MA crosses the 50-day MA
Comparing different companies by changing a single ticker symbol
